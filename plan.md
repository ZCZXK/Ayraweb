

## Public DNS availability note — 2026-11-06
The portfolio code is in the READY Vercel production deployment for commit `8ecbbc1e40221a6a664b45e3e6997b07595320d6`, and Vercel lists `cf7yce.ayrabot.fun` as attached and verified. Vercel's zone already contains root and wildcard ALIAS records for the production target. However, public DNS-over-HTTPS returned NXDOMAIN for `ayrabot.fun`, `www`, `support`, `snicker`, and `cf7yce`. The domain's RDAP record lists `client hold`, Vercel nameservers, and an expiration date in 2027. ICANN explains that `clientHold` is set by the registrar and prevents DNS activation. Vercel's domain config also reports `misconfigured: true`. No DNS, nameserver, or registrar settings were changed. The owner must ask the domain registrar to resolve the hold; then confirm public DNS resolves before treating the custom host as publicly reachable. Sources: [RDAP record](https://rdap.org/domain/ayrabot.fun) and [ICANN EPP Status Codes](https://www.icann.org/resources/pages/epp-status-codes-2014-06-16-en).

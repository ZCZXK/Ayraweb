# Ayraweb — Coming Soon

A minimal Next.js landing page for Vercel, with an editorial coming-soon message, a vinyl illustration, and a direct link to “I Wanna Be Yours” by Arctic Monkeys on Spotify. The track itself is not embedded or previewed on the page.

## Run locally

```sh
pnpm install
pnpm dev
```

## Deploy to Vercel

Import `ZCZXK/Ayraweb` into Vercel and use the detected Next.js defaults. The build command is `pnpm build`. This landing page requires no database, Hyperdrive binding, or environment variables.

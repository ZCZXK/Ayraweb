# Ayraweb — Coming Soon

A lightweight Next.js landing page for Vercel, with a custom animated vinyl player for the official Spotify embed of “I Wanna Be Yours” by Arctic Monkeys.

## Run locally

```sh
pnpm install
pnpm dev
```

## Deploy to Vercel

Import the GitHub repository `ZCZXK/Ayraweb` into Vercel and use the detected Next.js defaults. The build command is `pnpm build`; no database, Hyperdrive binding, or environment variables are required for this landing page.

The track is served by Spotify’s official embed. Visitors can use the custom play button or open the track directly in Spotify. Playback availability depends on Spotify and the visitor’s browser/account.
